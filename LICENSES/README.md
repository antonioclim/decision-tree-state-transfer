# Licence texts and notices

- `PolyForm-Noncommercial-1.0.0.txt` is the verbatim standard software licence.
- `CC-BY-NC-4.0.txt` and `CC-BY-4.0.txt` are the standard Creative Commons legal texts.
- `PDDL-1.0-NOTICE.txt` points to the authoritative upstream legal text for ELEC2.
- `LicenseRef-*` files define project-specific reserved-rights categories.

The root `LICENSE` covers original project software only. `LICENSE-POLICY.md` and `licensing/licence-map.json` define the multi-licence boundary. Third-party data and dependencies retain their own terms.
