# I05 — Resource measurement plan

For each arm, record separately:

1. deterministic APW;
2. process CPU time;
3. elapsed time;
4. peak RSS;
5. prediction latency;
6. end-state snapshot bytes;
7. provenance bytes and event counts;
8. source materialisation and parent-training receipts.

APW is comparable only across the three internal arms under a common work contract. CPU, elapsed and RSS are realised implementation quantities. No dimension is converted to money.

The primary resource comparison is paired and uses the same stream clusters as the predictive analysis. I07 may construct Pareto and hard-budget analyses only after realised I06 receipts exist.
