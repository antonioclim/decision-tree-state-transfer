# Contributing

Version 1.0.0 is the publication release corresponding to the locked scientific evidence. Proposed contributions must preserve the locked scientific contracts. No change may silently alter sample sizes, scenarios, arms, seeds, horizons, practical-equivalence margins, inferential families or reported results.

Use an issue or pull request in the public repository for documentation, portability or non-result-changing maintenance proposals. Changes that would affect scientific results require a new explicitly versioned study rather than an amendment to the archived release.
